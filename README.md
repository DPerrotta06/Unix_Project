# Unix_Project
 Script project for Unix that uses Bash on Rasbian OS. Functionalities are as stated:
 - Resource usage of your system
 - A file backup tool
 - Checking and managing all network interfaces on your device
 - Services manager on the raspberry pi
 - Adding, deleting or modifying users
 - VIewing 10 largest and smallest files based on what user is trying to access them
 - Sending an email
 - IS COLOR CODED
 - ERROR HANDLING
